# LaTeX layout adaptations

The existing classic template keeps its notice in LICENSE.txt. The new layouts also retain the classic template’s common macro/font-loading lineage (zheyuye/resume-chinese, MIT); LICENSE.txt remains applicable alongside the respective upstream notice, and exported builds include both full notices. New layouts share the project's escaped Markdown macro interface, local Noto Sans CJK fonts, logo macro, and Tectonic build pipeline. They are adaptations of public layout ideas and source; they are not unmodified upstream templates, nor an assertion that upstream supports this editor.

- **minimal.tex** adapts the single-column section-rule layout of [sb2nov/resume](https://github.com/sb2nov/resume/tree/7b70fe14876f97180034787f2a7f661597416a17), fixed commit `7b70fe14876f97180034787f2a7f661597416a17`. MIT, Copyright (c) 2026 Sourabh Bajaj. Full license: LICENSE.sb2nov.txt. Changed: shared Markdown macros, A4 geometry, Noto CJK font loading, wrapping entry headers, no upstream personal content.
- **two-column.tex** adapts the colored two-column layout of [jankapunkt/latexcv](https://github.com/jankapunkt/latexcv/tree/1fc7a2033ddda0fa77003444cafcf96117ad58dd/two_column), fixed commit `1fc7a2033ddda0fa77003444cafcf96117ad58dd`. MIT, repository Copyright (c) 2017 Jan Küster; original two_column/main.tex also carries Copyright (c) 2015 Jan Küster. Full license: LICENSE.latexcv.txt. Changed: sequential balanced columns using multicol, shared Markdown macros, Noto CJK font loading, no photos/QR/TikZ assets, no Roboto dependency. Original's specialized left/right profile blocks were replaced by sequential content so every layout retains the same Markdown.

No upstream personal photographs, QR codes, resume PDFs, proprietary fonts, or Font Awesome files are included. Noto font licenses continue to be installed by setup.py alongside their font files. Thumbnail images show only the repository's fictional public example content and are rendered from the actual LaTeX PDFs.
