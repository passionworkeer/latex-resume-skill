# 验证记录

验证日期：2026-10-21。公开测试只使用虚构材料；原始个人简历未加入本仓库。

## 检查范围

- 本地环境：macOS ARM64、Python 3.13、Tectonic 0.17.0。
- 从空的项目虚拟环境安装固定直接依赖，下载和校验字体，生成 Regular/Bold 静态字库。
- 模拟没有 PATH 编译器的情况，实际下载并执行固定版本的用户目录 Tectonic。
- 单元与回归检查：文本转义、Unicode、链接标签、错误输入、文字遗漏、页数、越界、缺字/替代字体/溢出日志、旧产物清理、源文件与软链接保护。
- 实际编译中文和英文虚构例子；正文逐字比对、页数、字形边界、编译日志检查和全部页面渲染。
- 独立 agent 使用额外的特殊字符与 URL 样例做前向验证；内容改写另有不夸大单次本地实验的行为演练。

示例 PDF 和预览在 `examples/`。与发布示例对应的哈希和验证结果在 `examples/validation.json`；机器报告不能替代视觉判断，视觉结果单独记录。

## 平台说明

安装器包含 macOS/Linux ARM64 与 x86_64、Windows x86_64 的官方下载和校验清单。配置了 Ubuntu、macOS、Windows 的 GitHub Actions，真实云端状态以仓库 Actions 对应提交为准，不能把配置存在当作全部平台测试通过。

本地未验证 XeLaTeX 路径、Windows ARM、其他 Linux 发行版、商业字体、任意 OCR 引擎或所有多栏模板。PDF/PNG 模板复刻是一套给 agent 执行的测量、重建和视觉比较流程，不是通用的像素自动转换器。

## 本轮修正

- 创建虚拟环境前解析 Python 启动器的真实路径，避免某些符号链接安装记录错误的标准库目录。
- 构建前清理本工具已知的旧 PDF、预览和报告，避免新编译失败后沿用旧结果；保护输入文件和无关文件。
- Windows 本地编译器路径包含 `.exe`。
- 缺失或空的指定编译日志报错；不提供日志时不能得到整体通过。
- 默认字体禁用会改变 ASCII 字符序列的排版连字；保持严格文字比对。

- 为中点、列表圆点和连字符建立独立字形映射，避免 PDF 提取把标点变成其他字符；通过保存/重载字体的回归检查。

## v0.2 编辑器与图标

- 27 项本地测试通过，新增 Host/Origin/令牌校验、草稿保存与导入冲突、并发锁、错误/超时、预览顺序、进程树清理、SVG 校验与矢量转换。
- 28 个 SVG 的固定来源、SHA-256 和元素白名单全部核对；逐个转换为矢量 PDF。Windows 超时清理分支由 mock 验证，POSIX 父孙进程清理由真实子进程验证。
- 中文、英文和图标三个虚构示例均实际编译、逐字比对、单页/边界/日志检查通过，所有最终页面已人工视觉检查。对应哈希在 examples/validation.json。
- 现有外部 Chrome 原生界面验证：初次生成真实 PNG/PDF，手动修改中文与数字后显示旧预览过期，图标选择器正确插入 GitHub 标记，再次生成新 PDF；不闭合加粗输入失败时草稿仍保存、旧 PDF 标为过期。
- 本机曾高负载导致旧 180 秒限制超时；上限调整为 600 秒并清理整个本次编译进程树。没有终止其他任务进程。
- 浏览器交互验证仅覆盖本机桌面 Chrome；没有声称已测试所有浏览器或移动设备。GitHub Actions 对三个平台的后端测试与全部示例构建以最终提交状态为准。

- 跨平台回归修正：测试草稿显式按 UTF-8 读取，下载接口逐字节保留文件；编译子进程显式输出 UTF-8。JSON 传输大小上限容纳转义开销，解码后的源码仍严格限制为 200000 字节。

## v0.3 自动 LaTeX 预览

- 36 项 Python 测试与 2 项前端状态测试通过，覆盖草稿/字号恢复、并发保存、缓存回退和版本绑定导出；ByteMD 生产包可由锁定依赖重新构建。
- 外部桌面 Chrome 实测：追加中文与数字、按钮加粗、11 pt 字号均自动排版；不闭合加粗时保存草稿并禁用旧 PDF/PNG 导出；撤销后自动恢复。PDF、PNG 与 Markdown 下载逐字节等于本次构建 PDF、页面和当前草稿。
- 中文、英文和图标三个最终发布样例重新编译、全文/单页/边界/日志检查通过，逐页视觉检查无重叠、裁切。报告绑定新模板与 PDF 哈希。
- 前端只复用 ByteMD 编辑部分，右侧是 LaTeX PDF 渲染出的 PNG；没有 HTML 简历打印路径。UI 为独立 CSS，未引入 UNLICENSED 的 Tea npm 包。完整前端第三方许可随源码和预构建包发布。
- 自动编译在停止输入 650 ms 后触发，完成仍需要编译与验证时间；首次资源下载、机器负载和文档长度会影响延迟。未声称逐键瞬时渲染；中文文本输入和粘贴已测，系统中文 IME 组合输入未单独覆盖。

- 首次 v0.3 Windows CI 发现草稿保存时 LF 被平台转换为 CRLF；改为写入明确的 UTF-8 字节，保持下载/备份内容一致，保留原严格逐字节断言。
